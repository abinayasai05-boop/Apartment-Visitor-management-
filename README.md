Apartment Visitor Management System

A simple frontend project for apartment visitor management.

Live webpage https://abinayasai05-boop.github.io/Apartment-Visitor-management-/
Features

- Visitor Entry Form
- QR Pass Section
- Resident Dashboard
- Security Panel

Technologies

- HTML
- CSS

Note

This is a frontend-only project. It does not include a database, backend, authentication, or real QR code generation.
